# Tessera
Real-Time granular processing

---

Tessera is the product of a my final project at Maynooth University.
It is a a real-time granular processing effect written in c++ using the juce framework.

---

# Cloning

Click the green "Code" button for .git link for project.
open terminal of choice and navigate to the location you wish to store the project and use this command:

`git clone --recurse-submodule https://github.com/audioev/Tessera.git`

The repo should be populated with modules to that location.

---
# Build

I advise using the CLion IDE by JETBRAINS, as downloading this ide downloads Cmake, and has direct Cmake support.

once cloned, open in the ide and navigate to the `CMakeLists.txt` file. Your ide may ask for inital settings, navigate this how you wish.

Reload the CMake Project and build.

If there are any issues with this, feel free to post questions in the issues tab.
